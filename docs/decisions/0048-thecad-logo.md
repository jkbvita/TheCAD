# 0048 — TheCAD logo and Windows app icon

Status: owner approved on 2026-11-09 in the UI design chat.

Help → About displays the supplied full logo and wordmark. The Windows
executable and application windows use the orange and blue TC mark. The icon
uses a transparent vector trace of the supplied mark, with sizes from 16 to
256 pixels for Windows. The full logo is embedded as the owner supplied it.

Qt resources and the existing Windows resource compiler bundle the assets in
the executable. No new build or runtime dependency is required.
