# TheCAD

TheCAD aims to be a free, open-source parametric mechanical CAD application.
Its long-term scope includes part modeling, parametric sketches, assemblies,
technical drawings, and customizable workflows.

The project is in the requirements and decision stage. No CAD features are
implemented, and no CAD engine, framework, or architecture has been selected.
